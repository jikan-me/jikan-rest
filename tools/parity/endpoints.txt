# Parity endpoint set for the Lumen -> Laravel migration.
#
# One endpoint per line: "METHOD /path" (METHOD optional, defaults to GET).
# Lines starting with # are ignored.
#
# Choose endpoints that cover every controller/feature family. Prefer
# concrete IDs over random/search endpoints where possible, because those are
# deterministic. `snapshot.php` captures the response *shape* (keys + types,
# volatile fields masked) plus the HTTP status, so the harness survives live
# MyAnimeList data drift.
